# Architecture decision records

This directory holds the architecture decision records (ADRs) for the wger Cloudron package,
numbered sequentially from `0001` upwards in filename order (for example
`0001-build-shape.md`). Each ADR is added at the point its decision is actually made, not
reserved in advance, so the numbering reflects the order decisions were taken during packaging
rather than a fixed plan drawn up beforehand.
